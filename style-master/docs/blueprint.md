# **App Name**: StyleWise AI

## Core Features:

- Intelligent Product Search: AI 에이전트를 이용하여 사용자가 원하는 여성의류를 찾아줍니다 (멀티 툴 에이전트 활용).
- Predictive Trend Setter: 사용자 선호도에 따라 제품 트렌드를 분석하고 예측합니다.
- Dynamic Menu: '최신', '인기', '전체', 'AI 스타일리스트' 메뉴를 통해 쉽게 탐색할 수 있습니다.
- AI Image Generation: 제품 페이지에서 AI를 사용하여 상세한 제품 이미지를 생성합니다 (멀티 툴 프롬프팅 활용).
- Dynamic layout: 20대 여성에게 어필할 수 있는 현대적이고 역동적인 레이아웃을 제공합니다.

## Style Guidelines:

- 20대의 역동적인 에너지를 담아내는 강렬한 보라색 (#A020F0)을 사용합니다.
- 주요 색상을 보완하고 충분한 대비를 제공하는 매우 밝은 보라색 (#F0E5FF)을 배경색으로 사용합니다.
- 주요 색상과 대비를 이루고 CTA에 시선을 끌기 위해 밝은 분홍색 (#F020A0)을 사용합니다.
- 현대적이고 세련된 느낌을 주는 'Space Grotesk' (산세리프) 글꼴을 제목 및 짧은 본문 텍스트에 사용합니다.
- 깨끗하고 현대적인 인터페이스를 유지하기 위해 최소한의 벡터 기반 아이콘을 사용합니다.
- 사용자 참여를 유도하고 젊음의 에너지를 반영하기 위해 미묘하고 역동적인 애니메이션을 통합합니다.
- 시각적 스토리텔링과 쉬운 탐색을 강조하면서 모바일과 데스크톱 모두에 최적화된 반응형 레이아웃을 제공합니다.
